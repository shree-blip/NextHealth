## Content Quality Standards

### Every Piece Must Have

| Element | Standard |
|---|---|
| Word Count | Blog: 1,200–2,500 / News: 600–1,200 / Pages: 1,000–2,000 |
| Primary Keyword | In title, H1, first 100 words, meta description |
| Internal Links | ≥3 outbound to other site pages |
| CTA | At least 1 clear call to action |
| Schema | Article, FAQ, or relevant type |
| Metadata | Title (50–60 chars), description (150–160 chars), OG tags |
| Images | ≥1 with alt text; hero image for blog/news |
| Readability | Flesch Reading Ease: 60+ (plain language) |
| E-E-A-T Signals | Author byline, credentials, sources cited |
| British English | UK spelling throughout (optimise, organisation, programme, etc.) |

## Risk Mitigation

| Risk | Mitigation |
|---|---|
| Writer bandwidth shortfall | Maintain 4-week content buffer; identify backup writers |
| Content quality inconsistency | Enforce style guide + SEO checklist; require editorial review |
| Client data delays (case studies) | Maintain 2 backup case study briefs; use anonymised data |
| Industry news drought | Maintain evergreen news topic backlog (20 topics) |
| Keyword cannibalisation | Map every keyword to exactly 1 page; monthly audit |
| Content decay after 6 months | Quarterly refresh cycle built into plan |
