# Metadata Blueprint

**Site:** thenextgenhealth.com
**Blueprint Date:** 8 April 2026

> Complete metadata specifications for all existing pages and future pages. Includes title tags, meta descriptions, Open Graph, Twitter Cards, and canonical URLs.

---

## Metadata Standards

### Title Tag Rules
- **Format:** `[Primary Keyword] — [Modifier/USP] | NextGen Health`
- **Max length:** 60 characters (including brand)
- **Must contain:** Primary keyword + brand name
- **Separator:** Use `|` between content and brand
- **No duplicates:** Every page must have a unique title

### Meta Description Rules
- **Max length:** 155 characters
- **Structure:** `[Value proposition]. [Benefit]. [CTA].`
- **Must contain:** Primary keyword + CTA verb
- **No duplicates:** Every page must have a unique description

### Open Graph Rules
- `og:title` — Mirror title tag (can exclude brand suffix)
- `og:description` — Mirror meta description
- `og:image` — Custom 1200×630px image per page (or per section)
- `og:url` — Canonical URL
- `og:type` — `website` for pages, `article` for blog/news
- `og:site_name` — `NextGen Health`

### Twitter Card Rules
- `twitter:card` — `summary_large_image`
- `twitter:title` — Mirror og:title
- `twitter:description` — Mirror og:description
- `twitter:image` — Mirror og:image

### Canonical URL Rules
- Every page must have a self-referencing canonical
- Format: `https://thenextgenhealth.com/[path]`
- No trailing slash (unless that's the consistent URL format)
- Always HTTPS
- Redirected pages: canonical on destination URL only

## Implementation in Next.js

### Metadata API Pattern

Each page's `layout.tsx` or `page.tsx` should export metadata:

```tsx
import type { Metadata } from 'next';

export const metadata: Metadata = {
  title: 'Healthcare SEO & Local Search Services | NextGen Health',
  description: 'Rank higher on Google with healthcare SEO and local search optimisation...',
  openGraph: {
    title: 'Healthcare SEO & Local Search Services',
    description: 'Rank higher on Google with healthcare SEO...',
    url: 'https://thenextgenhealth.com/services/seo-local-search',
    siteName: 'NextGen Health',
    type: 'website',
    images: [{
      url: 'https://thenextgenhealth.com/og/seo-local-search.jpg',
      width: 1200,
      height: 630,
      alt: 'Healthcare SEO Services by NextGen Health',
    }],
  },
  twitter: {
    card: 'summary_large_image',
    title: 'Healthcare SEO & Local Search Services',
    description: 'Rank higher on Google with healthcare SEO...',
  },
  alternates: {
    canonical: 'https://thenextgenhealth.com/services/seo-local-search',
  },
};
```

### Dynamic Metadata for Blog/News

```tsx
export async function generateMetadata({ params }): Promise<Metadata> {
  const post = await getPost(params.slug);
  return {
    title: `${post.title} | NextGen Health`,
    description: post.excerpt,
    openGraph: {
      type: 'article',
      publishedTime: post.publishedAt,
      modifiedTime: post.updatedAt,
      authors: [post.author?.name],
      ...
    },
  };
}
```
