## Universal Blog Post Template

### Front Matter

```
Title: [SEO-optimised, 50–60 chars]
Meta Description: [155 chars with CTA]
Slug: /blog/[keyword-rich-slug]
Author: [Team member name]
Published: [Date]
Updated: [Date]
Category: [Cluster name]
Tags: [3–5 relevant tags]
Featured Image: [Descriptive filename, proper alt text]
```

### Required Page Elements

1. **Breadcrumb** — Home > Blog > [Post Title]
2. **Author byline** — Name, role, headshot, link to author page
3. **Published / Updated dates** — Visible on page
4. **Table of Contents** — Auto-generated from H2/H3 headings (for posts 1,500+ words)
5. **Article schema** — JSON-LD
6. **Internal links** — Minimum 3 outbound to service/core pages
7. **Related posts** — 3 related articles at bottom
8. **CTA** — Contextual CTA within content + bottom CTA block
9. **Social share buttons** — Twitter, LinkedIn, Facebook
10. **Category/tag links** — Link to filtered blog views

### Content Structure

```
H1: [Title — contains primary keyword]
  Intro paragraph (hook + keyword + what they'll learn)
  
  H2: [Section 1 — contains secondary keyword]
    Body content
    [Internal link to relevant service page]
    
  H2: [Section 2 — contains secondary keyword]
    Body content
    H3: [Sub-section if needed]
    
  H2: [Section 3]
    Body content
    [Internal link to related blog post]
    
  H2: Key Takeaways / Summary
    Bullet-point summary
    
  H2: Ready to [Action]? (CTA section)
    CTA paragraph + button to /book-a-demo
```

## Content Quality Standards

| Standard | Requirement |
|---|---|
| Language | British English throughout |
| Tone | Professional, authoritative, accessible |
| Sourcing | Cite reputable sources (NHS, CDC, CMS, Google, peer-reviewed) |
| Accuracy | All medical/legal claims must be fact-checked |
| Disclaimers | Medical content requires "not medical advice" disclaimer |
| HIPAA references | Must be accurate and current |
| CTAs | Every post ends with contextual CTA |
| Images | Min 2 per post, all with descriptive alt text |
| Formatting | Use bullet points, tables, and subheadings liberally |
| Readability | Target grade 8–10 reading level |
